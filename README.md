# TaskFlow

A simple and clean RESTful API for managing personal tasks, built with Go.

## Project Status

🚧 In Development

An educational project focused on learning Go, clean code, and backend development best practices.

## Features

### Current Features
- Basic HTTP server using Go's `net/http` package
- Clean and organized code structure
- Separated constants and functions
- Basic error handling

### Planned Features
- [ ] JWT Authentication
- [ ] Task CRUD Operations
- [ ] Database Integration (SQLite / PostgreSQL)
- [ ] Filtering and Search
- [ ] Input Validation

## Getting Started

### Prerequisites
- Go 1.XX or higher

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd TaskFlow
```

### Run the Project

```bash
go run main.go
```

## Tech Stack

- **Language:** Go
- **HTTP Server:** net/http
- **Database:** SQLite / PostgreSQL (Planned)
- **Authentication:** JWT (Planned)
